# ApiViewer 隐私政策

生效日期：2026 年 8 月 29 日

版本：1.0

## 简要说明

ApiViewer 仅在用户主动打开侧边栏并明确同意后，读取当前标签页的 Fetch / XHR 网络请求。捕获记录只在浏览器运行内存中处理，不会上传到 ApiViewer 开发者控制的服务器，关闭侧边栏后即被清除。

## 1. 适用范围

本政策适用于 Chrome 扩展程序 ApiViewer（以下简称“本扩展”）。本扩展的单一用途是帮助用户检查、复制和重放当前标签页的 Fetch / XHR 网络请求。

## 2. 本扩展处理的数据

为提供上述功能，本扩展可能处理：

- 当前标签页的网页地址和标题；
- Fetch / XHR 请求的 URL、HTTP 方法、状态码、耗时及大小；
- 请求头、响应头、请求体和响应体；
- 请求中可能包含的 Cookie、Authorization 标头或其他认证信息；
- 用户在重放编辑器中输入或修改的 URL、参数、标头和请求体；
- 用户设置，例如最大请求数量、最大响应体大小和是否自动开始捕获。

请求和响应内容由用户访问的网站产生，可能包含个人身份信息、表单数据、个人通信、支付信息、健康信息或其他敏感内容。本扩展不会主动判断或分类这些内容。

## 3. 数据用途

数据只用于在侧边栏展示、搜索、筛选和格式化网络请求，生成或复制用户选择的内容，在用户明确操作后重放请求，以及在本机保存用户设置。

## 4. 本地处理、存储和保留期限

- 捕获到的请求和响应只保存在运行内存中，不写入持久化存储；
- 关闭侧边栏后，扩展会解除调试连接并清除当前捕获会话；
- 用户设置和隐私授权记录保存在 `chrome.storage.local`，直至用户清除扩展数据或卸载扩展；
- 本扩展不使用分析、遥测、广告或跨站追踪服务。

## 5. 数据传输和共享

本扩展不会把捕获内容上传、出售、出租或共享给 ApiViewer 开发者、广告商、数据经纪商或其他第三方。

用户主动使用“编辑并重发”时，本扩展会在当前页面上下文中，将用户确认的请求内容发送到用户填写的目标 URL。该传输受目标网站自身隐私政策约束。用户主动复制内容后，数据会进入系统剪贴板，并由用户自行决定后续用途。

## 6. 权限说明

- `debugger`：仅在侧边栏打开且用户已授权时，通过 Chrome DevTools Protocol 读取当前标签页 Fetch / XHR，关闭侧边栏后断开。
- `sidePanel`：展示扩展界面。
- `tabs`：识别当前活动标签页及其 URL 和标题，并在标签页切换时更新目标。
- `storage`：在本机保存设置和隐私授权记录。
- `clipboardWrite`：仅在用户点击复制按钮后写入剪贴板。

## 7. 安全和用户控制

本扩展采用 Manifest V3，不下载或执行远程代码。用户可以暂停捕获、清空记录、关闭侧边栏、清除扩展存储或卸载扩展。复制的 cURL、请求头或正文可能包含敏感信息，请勿分享给不受信任的人。

## 8. Chrome Web Store Limited Use

本扩展对通过 Chrome 扩展 API 获得的数据的使用，遵守 Chrome Web Store 用户数据政策及其 Limited Use（有限使用）要求。数据只用于提供或改进本扩展公开说明的单一用途，不用于个性化广告、信用评估、数据转售或与单一用途无关的用户画像。

## 9. 政策变更

如果数据处理方式发生实质变化，我们会在收集或使用相关数据前，通过扩展界面显著披露变化并重新取得必要的明确同意，同时更新本政策日期。
