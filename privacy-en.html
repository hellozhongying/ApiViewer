ApiViewer

Privacy Policy

Effective August 29, 2026 · Version 1.0

Summary

ApiViewer reads Fetch / XHR network requests from the current tab only after you open the side panel and explicitly agree. Captured records are processed only in browser memory, are never uploaded to servers controlled by the ApiViewer developer, and are cleared when the side panel closes.

1. Scope

This policy applies to the ApiViewer Chrome extension (the “extension”). Its sole purpose is to help you inspect, copy, and replay Fetch / XHR network requests from the current tab.

2. Data the extension processes

To provide these features, the extension may process:

  • The current tab's URL and title;
  • Fetch / XHR request URLs, HTTP methods, status codes, durations, and sizes;
  • Request headers, response headers, request bodies, and response bodies;
  • Cookies, Authorization headers, or other authentication information that a request may contain;
  • URLs, parameters, headers, and request bodies that you enter or modify in the replay editor; and
  • Settings such as the request limit, response body size limit, and automatic capture preference.

Request and response content comes from websites you visit and may contain personally identifiable information, form data, personal communications, payment information, health information, or other sensitive content. The extension does not attempt to identify or classify this content.

3. How data is used

The data is used only to provide the features shown in the extension, including:

  • Displaying Fetch / XHR requests and their details in the side panel;
  • Searching, filtering, formatting, and copying captured content;
  • Generating cURL and copying it to the clipboard after an explicit user action;
  • Replaying a request to a destination specified by the user with user-edited content; and
  • Saving extension settings locally.

4. Local processing, storage, and retention

  • Captured network requests and responses remain only in extension memory and are not written to persistent storage;
  • When the ApiViewer side panel closes, the extension disconnects the debugger and clears the current capture session;
  • Settings and the privacy consent record are stored in chrome.storage.local until you clear extension data or uninstall the extension; and
  • The extension does not use analytics, telemetry, advertising, or cross-site tracking services.

5. Data transfer and sharing

The extension does not upload, sell, rent, or share captured content with the ApiViewer developer, advertisers, data brokers, or other third parties.

When you explicitly use Edit and resend, the extension sends the request content you confirm to the destination URL you enter, in the context of the current page. This is a network request initiated by you and is subject to the destination website's privacy policy. When you copy content, it enters the system clipboard and you control how it is used afterward.

6. Permissions

debugger
Reads Fetch / XHR requests from the current tab through the Chrome DevTools Protocol only while the side panel is open and permission has been granted; it disconnects when the panel closes.
sidePanel
Displays the extension in Chrome's native side panel.
tabs
Identifies the active tab, displays its URL and title, and updates the inspection target when you switch tabs.
storage
Stores extension settings and the privacy consent record locally.
clipboardWrite
Writes to the clipboard only after you click a copy button.

7. Data security and user control

The extension uses Manifest V3 and does not download or execute remote code. You can pause capture, clear current records, close the side panel, clear extension storage, or uninstall the extension at any time. Copied cURL commands, headers, or bodies may contain sensitive information; do not share them with untrusted parties.

8. Chrome Web Store Limited Use

The extension's use of information received from Chrome extension APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve the extension's disclosed single purpose. It is not used for personalized advertising, credit assessment, data resale, or user profiling unrelated to that purpose.

9. Changes to this policy

If our data handling changes materially, we will prominently disclose the change in the extension and obtain any required renewed consent before collecting or using the affected data. We will also update the effective date of this policy.
